# Sidebar Tabs

Компактная панель вкладок в боковой панели Firefox — с нативными группами,
плеером, громкостью для каждой вкладки и автосохранением сессии на случай краша.

## Возможности

**Вкладки**
- Вертикальный список вкладок в боковой панели: закреплённые сверху, компактные строки.
- Нативные группы вкладок Firefox — создание, сворачивание, перетаскивание целых групп, «+» на заголовке — новая вкладка сразу в группе.
- Перетаскивание вкладок и групп мышью, в том числе нескольких сразу.
- Кнопки «Выгрузить» (освободить память) и «Закрыть» вкладки вне групп.
- **Недавно закрытые** — блок над плеером: вкладки, закрытые в этом окне, и закрытые окна. Клик возвращает вкладку с её историей, крестик или средняя кнопка убирает строку из списка.
- **Дубликаты** — значок у вкладок с одним и тем же адресом. Клик по значку закрывает остальные копии, кнопка сверху закрывает все лишние; закреплённые вкладки не закрываются, из остальных остаётся активная или загруженная копия.
- **Контейнеры Firefox** — цветная полоска справа у вкладки. В контекстном меню есть «Открыть в контейнере» и «Новая вкладка в контейнере». Автосохранение помнит контейнер вкладки.
- **Автогруппировка** — правила вида «`github.com` → группа „Код“»: вкладка, открывшая подходящий адрес, сама попадает в группу. Вкладку, которую вынули из группы руками, правило обратно не тянет.
- Иконки сайтов видны даже у ещё не загруженных вкладок — из кэша, без загрузки страниц.
- Цвета подстраиваются под системную тему и тему Firefox.

**Звук и плеер**
- Громкость для каждой вкладки отдельно: клик по динамику — выключить звук, наведение — ползунок, колесо — ±5 %.
- Плагины для плеера: кнопки сайтов прямо в строке трека — например, «+ в мою музыку» для ВКонтакте. Включаются кнопкой с пазлом; как написать свой — [plugins/README.md](plugins/README.md).
- Микрофон вкладки: пока сайт его пишет (звонок, запись), в строке вкладки виден значок микрофона — клик выключает (сайт слышит тишину), наведение — ползунок громкости, колесо — ±5 %. Работает для захватов, начатых после установки расширения.
- Плеер внизу панели для всех играющих вкладок: обложка, название, пауза, предыдущий/следующий трек, перемотка ±10 с, полоса позиции.
- Скорость воспроизведения: значок «1×» в плеере. Клик открывает меню скоростей, колесо меняет скорость на ±0,25×. Следующий трек на том же сайте играет с той же скоростью.
- Работает с сайтами через Media Session API и с обычными `<audio>`/`<video>`.

**Горячие клавиши и настройки**
- Свои команды: выключить микрофон звонка из любой вкладки (<kbd>Ctrl+Alt+M</kbd>), пауза в плеере (<kbd>Ctrl+Alt+P</kbd>), скорость (<kbd>Ctrl+Alt+.</kbd> и <kbd>Ctrl+Alt+,</kbd>), следующий и предыдущий трек, закрыть дубликаты, показать или скрыть панель.
- Подсказки клавиш в меню и подсказках кнопок. Сочетания своих команд панель берёт у Firefox, поэтому переназначенные клавиши видны сразу. Для стандартных клавиш Firefox (<kbd>Ctrl+T</kbd>, <kbd>Ctrl+W</kbd>, <kbd>Ctrl+M</kbd>…) показываются стандартные сочетания.
- Страница настроек (шестерёнка в панели или `about:addons`): переключатели для блоков панели, редактор правил автогруппировки с проверкой адреса и назначение горячих клавиш прямо с клавиатуры.

**Автосохранение**
- Открытые окна, вкладки и группы сохраняются в фоне при каждом изменении (не чаще раза в 400 мс и не реже раза в 2 с).
- После краша браузера или отключения питания сессия восстанавливается автоматически при запуске.
- Восстановленные вкладки не загружаются, пока на них не кликнуть, — запуск остаётся быстрым даже с сотнями вкладок.

## Установка

Расширение не подписано в addons.mozilla.org, поэтому ставится в
**Firefox Developer Edition** или **Nightly**:

1. Скачайте `sidebar-tabs.xpi` из [последнего релиза](../../releases/latest) или соберите сами: `./build.sh` → `dist/sidebar-tabs.xpi`.
2. В `about:config` установите `xpinstall.signatures.required` = `false`.
3. `about:addons` → ⚙ → «Установить дополнение из файла…» → выберите `.xpi`.

Для быстрой проверки без установки подойдёт `about:debugging` → «Этот Firefox» → «Загрузить временное дополнение» → `manifest.json`.

### Скрыть встроенную полосу вкладок

Расширение не может само убрать стандартные вкладки Firefox над адресной строкой —
это делается стилями `userChrome.css`. Скрипт настроит всё за вас (Linux и macOS):

```sh
./userchrome/install.sh
```

Скрипт скрывает горизонтальную полосу вкладок (кнопки окна остаются) и заголовок
«Вкладки ✕» над боковой панелью, а также включает в `user.js` загрузку
`userChrome.css` и выключает встроенные вертикальные вкладки — с ними стили не
работают. Свои стили и настройки в этих файлах сохраняются, перед первым изменением
файла рядом кладётся копия `*.sidebar-tabs.bak`. Изменения вступают в силу после
перезапуска Firefox.

- Несколько профилей — скрипт спросит, в какой ставить; `--all` — во все, `--profile ПУТЬ` — в указанный (путь — в `about:profiles`).
- Отменить: `./userchrome/install.sh --uninstall`.

## Разработка

Проект на чистом JavaScript без сборщиков и npm-зависимостей.

```
manifest.json        — манифест (Manifest V2)
background.js        — автосохранение и восстановление сессии, кэш иконок, громкость, состояние плеера
content/media.js     — перехват медиа на страницах (Media Session, <audio>/<video>, громкость)
content/mic.js       — громкость и выключение микрофона (перехват getUserMedia)
content/plugin-api.js — API плагинов на странице (SidebarTabs)
plugins/             — плагины плеера (см. plugins/README.md)
shared/settings.js   — настройки, правила автогруппировки, вид горячих клавиш (общие для фона, панели и настроек)
sidebar/             — интерфейс боковой панели (model.js — чистая логика, sidebar.js — DOM)
options/             — страница настроек
icons/               — иконка расширения и иконки Lucide
test/                — модульные тесты (node:test) с фейковым browser.* API
e2e/                 — сквозные тесты плеера в настоящем Firefox и съёмка скриншотов
userchrome/          — install.sh: скрытие встроенной полосы вкладок через userChrome.css
docs/                — скриншоты для README
```

```sh
npm test        # модульные тесты, нужен Node.js 22+
npm run e2e     # сквозные тесты, нужен Firefox Developer Edition (FIREFOX=/путь/к/firefox)
./build.sh      # собрать dist/sidebar-tabs.xpi
npm run screenshots  # переснять docs/*.png (Firefox Developer Edition)
```
